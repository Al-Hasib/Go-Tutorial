# Go Tutorial

This repository is a beginner-friendly Go language learning project. It contains small, focused Go programs that introduce core concepts step by step.

## Purpose

The goal of this repo is to teach the fundamentals of Go programming through simple examples and practical exercises. Each file builds on the previous one and covers essential topics such as:

- Variables and values
- Constants
- Operators
- Conditions
- Loops
- Arrays and slices
- Maps
- Functions
- Range over collections
- Basic Go syntax and program structure

## Files

- `1_hello.go` — Hello World example
- `2_value_variable.go` — Variables and values
- `3_constants.go` — Constants
- `4_operators.go` — Arithmetic and comparison operators
- `5_conditions.go` — If/else conditions
- `6_loops.go` — Loop structures
- `7_arrays.go` — Arrays
- `8_slices.go` — Slices
- `9_maps.go` — Maps
- `10_range.go` — Range keyword
- `11_functions.go` — Function definitions and usage

## How to run

From the project directory, run a Go file with:

```bash
go run 1_hello.go
```

You can replace the filename with any lesson you want to try.

## Prerequisites

Make sure Go is installed on your machine.

- Download: https://go.dev/dl/
- Verify installation:

```bash
go version
```

## Learning path

Start from the lowest numbered file and move upward in order. Each file is designed to introduce one concept at a time.

## Notes

This repository is intended for learning and experimentation. You can modify the example files to test different values and behavior.
